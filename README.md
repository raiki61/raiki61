# raiki61

普段の開発で気づいた摩擦を、Claude Code用のプラグインにして直しています。

## 作ったもの

- [claude-review-loops](https://github.com/raiki61/claude-review-loops) — 収束するまで回すレビューループと調査ループ。実装者(writer)と採点者(grader)を別contextに分離し、収束を機械に宣言させない設計
- [tab-tint](https://github.com/raiki61/tab-tint) — Claude Codeが応答待ちの間だけターミナル背景を控えめに変えるフックプラグイン
